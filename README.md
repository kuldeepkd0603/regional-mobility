# Raahi – Regional Mobility Monorepo

> **Your City. Your Ride. Your Way.**  
> Official repository for Raahi Regional Mobility platform, powering regional travel across Ujjain, Indore, and Dewas.

---

## 📂 Repository Structure

* **[`website/`](file:///c:/regional-mobility/website)**: Official Next.js 16 production website with TypeScript, Tailwind CSS, and Framer Motion. Detailed documentation is in [`website/README.md`](file:///c:/regional-mobility/website/README.md).
* **`mobile/`**: Cross-platform Flutter mobile applications (Raahi Passenger App & Raahi Driver App).
* **`backend/`**: Platform backend services and APIs.
* **`docs/`**: Brand assets, passenger app screens, and architecture specifications.

---

## 🌐 Quick Start: Website

To run the official Raahi website locally:

```powershell
cd website
pnpm install
pnpm dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.
